# Standalone Rust IPP Printer App

## Summary

Build a Dockerized Rust printer application that exposes an IPP printer endpoint, accepts print jobs, converts raster label pages into the Vevor label printer command stream, and writes the result to a USB printer device.

## Requirements

- Run as a standalone Docker image without requiring CUPS inside the container.
- Expose an IPP endpoint suitable for driverless clients to discover and print to.
- Keep the Vevor printer driver logic independent from IPP, HTTP, Docker, and USB transport.
- Support direct output to a device path such as `/dev/usb/lp0`.
- Start with a minimal IPP implementation and grow toward IPP Everywhere compatibility.
- Preserve the existing legacy CUPS driver files while the Rust app is developed.

## Initial Scope

- HTTP service with health endpoint and IPP POST endpoint.
- Minimal IPP request parsing and response encoding for printer/job operations.
- Printer attributes describing one 300 DPI monochrome label printer.
- Driver module boundary for raster-to-Vevor command conversion.
- Output abstraction for writing generated bytes to a configured file/device.
- Dockerfile for containerized runtime.

## Out Of Scope For First Pass

- Full IPP Everywhere certification.
- PDF rendering.
- AirPrint URF support.
- mDNS/DNS-SD advertisement.
- Complete port of every option from the legacy PPD.

## Follow-Up Work

- Implement PWG Raster parsing.
- Port raster conversion behavior from `rastertolabel.c` into the Rust driver module.
- Add mDNS advertisement for `_ipp._tcp`.
- Add PDF rendering through a small external renderer or internal rasterization pipeline.
- Add integration tests using captured IPP requests and sample raster pages.

## Testing Plan

- Run `cargo fmt --check`.
- Run `cargo test`.
- Run `cargo build`.
- Build the Docker image.
- Verify `GET /health` returns `ok`.
- Verify an IPP `Get-Printer-Attributes` request returns a syntactically valid IPP response.
- Verify print output can be redirected to a temporary file before using a real USB device.
